## September 2026

- New block: `otp-verify-card`. While a code is being verified, the slots
  become the loader (orbit, flip, spin, wave or pulse), always finishing at
  least one full rotation. Auto or manual submit, resend cooldown, and a
  headless `useOtpVerify` hook.
- Project scaffold: docs site, registry pipeline, MCP server, CLI, and the
  Next.js and React templates.
- First primitives: `button`, `input`, `field`, `spinner`, plus `theme` tokens.
