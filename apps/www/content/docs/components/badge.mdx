## Installation

```package-install
npx shadcn@latest add @fujin/badge
```

## Usage

```tsx
import { Badge } from "@/components/ui/badge"
```

```tsx
<Badge variant="success">Paid</Badge>
```

## What's different from shadcn/ui

Three extra variants - `success`, `warning`, `info` - use the status tokens
`@fujin/theme` adds. They need that theme item installed (`fujin init` does
this for you).
