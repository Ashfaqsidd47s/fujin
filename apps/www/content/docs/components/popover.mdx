## Installation

```package-install
npx shadcn@latest add @fujin/popover
```

## Usage

```tsx
import {
  Popover,
  PopoverContent,
  PopoverTrigger,
} from "@/components/ui/popover"
```

```tsx
<Popover>
  <PopoverTrigger render={<Button variant="outline">Filters</Button>} />
  <PopoverContent>...</PopoverContent>
</Popover>
```

## What's different from shadcn/ui

`render` replaces `asChild`, from Base UI - same as `button`.
